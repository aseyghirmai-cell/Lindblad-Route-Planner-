# Changelog

## 1.0.0

- Created a true static GitHub Pages application with no server component.
- Added local streaming OLEX gzip and `.olxidx.gz` indexing into OPFS geographic tiles.
- Added local RTZ library and editable RTZ import.
- Added interactive Canvas route review with OLEX traces, land, RTZ overlays and draggable waypoints.
- Added waypoint metadata editing, undo/redo, local route persistence and RTZ/JSON/CSV export.
- Added browser storage persistence request, usage display, local backup/restore and offline application-shell caching.
