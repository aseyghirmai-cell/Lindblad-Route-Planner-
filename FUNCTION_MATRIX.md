# Function matrix

| Function | Local-first GitHub Pages implementation |
|---|---|
| Original visual layout | Retained and extended |
| Historical destination search | Embedded catalogue, local worker |
| Historical route generation | Embedded graph, browser worker |
| OLEX database management | Local tiled browser index |
| Multiple OLEX databases | Supported, combined when enabled |
| RTZ library | Local import, visibility, edit copy, deletion |
| Passage schedule | Ship time, UTC offsets and UTC conversion |
| Required speed | Live calculation |
| Engine and fuel | Uses embedded NG Resolution configurations |
| Route summary | Live after generation and editing |
| Waypoint review | Full table and selected-waypoint inspector |
| Waypoint dragging | Interactive canvas map |
| Zoom and pan | Mouse wheel/buttons and background drag |
| OLEX background | Local depth traces beneath route |
| Waypoint properties | Name, position, radius, speed, XTD, wheel-over, geometry, remarks |
| Validation | Local automated checks |
| RTZ export | Supported |
| OLEX plot gzip export | Supported |
| Route persistence | IndexedDB, same workstation/browser profile |
| OLEX index persistence | Origin Private File System |
| Public URL | GitHub Pages |
| User login/cloud sync | Not included; incompatible with zero-cost static hosting |
