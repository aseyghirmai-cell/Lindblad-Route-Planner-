# Start here

1. Upload this package's contents to the root of a GitHub repository.
2. In GitHub, open **Settings → Pages** and select **GitHub Actions**.
3. Wait for the included `Deploy GitHub Pages` workflow to finish.
4. Open the public HTTPS address shown by GitHub.
5. In Chrome or Edge, click **Request persistent local storage**, then add RTZ and supported OLEX files.

No Docker, Caddy, server rental, payment card or desktop installation is required.

Read `DEPLOY_GITHUB_PAGES.md`, `OLEX_COMPATIBILITY.md` and `README.md` before using a large database.
